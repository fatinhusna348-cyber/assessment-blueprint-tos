# Assessment Blueprint & Table of Specifications

A self-contained, teacher-friendly assessment planning tool.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository**.
   Suggested repository name: `assessment-blueprint-tos`
2. Upload `index.html` to the **root** of the repository (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. GitHub will show the published website address in the Pages section.

## Important notes

- `index.html` must remain in the repository root for the site to open at its main address.
- This app does not require a build step, package manager, or external libraries.
- Drafts are saved in the browser's local storage on the current device/browser. They are not synchronised between teachers or devices.
- Use **Export full plan (JSON)** or **Export TOS (CSV)** to keep/share a copy of assessment plans.
- The Discrimination Index calculator is a post-test estimate using equal-sized upper and lower groups:
  `D = (U - L) / N`.
